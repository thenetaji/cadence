# Dev notes

## Commands (pnpm; there is no npm/npx, use `pnpm exec` / `pnpm dlx`)
- `pnpm start` run the dev server (`pnpm start --tunnel` if not on the same network)
- `pnpm typecheck` tsc strict | `pnpm lint` expo lint | `pnpm test` jest-expo
- `pnpm bundle:ios` Metro iOS export to `.export-ios` (proves it bundles on Linux)
- `pnpm bundle:web` web export to `.export-web`
- `pnpm run doctor` expo-doctor (plain `pnpm doctor` is a pnpm builtin) | `pnpm verify` typecheck + lint + test + bundle:ios
- `pnpm screenshots` web export, then `.screenshots/<name>-<light|dark>.png` (393x852 @3x)
  for each route in `scripts/screenshot-routes.json`; errors go to `.screenshots/console.log`
- `pnpm db:generate` drizzle-kit generates SQL migrations into `drizzle/`
- `pnpm typegen` regenerates typed routes after adding a route file

## Run on an iPhone (Expo Go)
Install Expo Go, run `pnpm start`, scan the QR code with the Camera app (same Wi-Fi),
or use `pnpm start --tunnel` when the phone cannot reach the machine.

## Styling
Uniwind 1.x + Tailwind 4 + React Native Reusables (`components.json`, `src/lib/utils.ts`):
chosen over NativeWind (v4 is Tailwind 3 and stale; v5 still pre-release) because Uniwind
is pure JS/Metro with no native module, so it runs in Expo Go and tracks the system scheme.
Theme tokens live in `src/global.css`; `src/uniwind-types.d.ts` is generated by Metro, commit it.

## Expo Go native-module rule
Every dependency with native code MUST be listed in `node_modules/expo/bundledNativeModules.json`
(add via `pnpm exec expo install`). Anything else needs a dev build, which we cannot make: forbidden.
Pure-JS libs (drizzle-orm, zustand, date-fns) are fine.

## expo-sqlite on web
Needs wasm in Metro `assetExts` and COOP/COEP headers; set in `metro.config.js` and the
screenshot server.
